# บ้านพร้อม — ระบบจัดการหอพัก

เว็บสำหรับเจ้าของหอพัก เก็บห้องพัก ผู้เช่า และค่าเช่าในฐานข้อมูล SQLite ฝั่งเซิร์ฟเวอร์
เริ่มต้นด้วยข้อมูลตัวอย่าง และบันทึกการแก้ไขลง `data/dorm.sqlite`
ข้อมูลยังอยู่หลังปิดเบราว์เซอร์และรีสตาร์ตเซิร์ฟเวอร์ ทุกหน้าที่เปิดจากเซิร์ฟเวอร์เดียวกันใช้ฐานข้อมูลเดียวกัน
การรับชำระเป็นการบันทึกรายการ ไม่มีการตัดเงินหรือเชื่อมบริการรับชำระ

## เปิด preview

```powershell
node server.mjs
```

เปิด http://127.0.0.1:4173

ใช้ Node.js 24 ขึ้นไป ตัวเว็บอยู่ใน `dist/` และใช้ SQLite ที่มากับ Node โดยไม่มี dependencies เพิ่มเติม

## ฐานข้อมูล

- `db/schema.sql` กำหนดตารางห้อง ผู้เช่า ค่าเช่า และข้อมูลเวอร์ชัน
- `db/database.mjs` จัดการตรวจข้อมูล ธุรกรรม และคำสั่ง SQL แบบเตรียมไว้
- `data/dorm.sqlite` เป็นฐานข้อมูลใช้งานจริงในเครื่องนี้ และไม่อยู่ในโฟลเดอร์ไฟล์สาธารณะ
- เมื่อย้ายออก ระบบเก็บผู้เช่าเป็นรายการย้อนหลังและเก็บใบค่าเช่าทั้งหมด
- การบันทึกตรวจเวอร์ชันข้อมูล ป้องกันหน้าเก่าทับการแก้ไขจากอีกหน้า และตรวจยอดล่าสุดก่อนรับชำระ
- ถ้าบันทึกไม่สำเร็จ ฟอร์มยังอยู่และไม่แสดงว่าบันทึกสำเร็จ

เมื่อเปิดที่ origin เดิม ระบบย้ายข้อมูลจากคีย์เดิม `baanprom-dorm-preview-v1` ให้โดยอัตโนมัติ
เฉพาะตอนฐานข้อมูลยังไม่มีการแก้ไข และเก็บสำเนาเดิมในเบราว์เซอร์ไว้ ไม่ใช้เป็นข้อมูลหลักอีกต่อไป
ฐานข้อมูลที่บันทึกแล้วจะไม่ถูกทับโดยข้อมูลเบราว์เซอร์เก่า

สำรองข้อมูล: หยุดเซิร์ฟเวอร์ด้วย Ctrl+C ก่อน แล้วคัดลอก `data/dorm.sqlite` ไปเก็บไว้

## ตรวจสอบ

```powershell
node verify-database.mjs
node verify-preview.cjs
```

ทั้งสองคำสั่งใช้ฐานข้อมูลทดสอบแยกใน `preview-checks/` ไม่แก้ฐานข้อมูลใช้งานจริง
การตรวจด้วยเบราว์เซอร์ใช้ Playwright ที่ติดตั้งใน runtime ของเครื่องนี้
ครอบคลุมการบันทึกข้ามเบราว์เซอร์และข้ามการรีสตาร์ต, ย้ายข้อมูลเดิม,
การย้อนธุรกรรมเมื่อบันทึกล้มเหลว, การแก้พร้อมกัน และการคงค่าฟอร์มเมื่อการเชื่อมต่อมีปัญหา

## ทดลองใช้งาน

- ภาพรวมและผัง 24 ห้องบน 3 ชั้น พร้อมยอดรับชำระและยอดค้าง
- ค้นหาและกรองห้อง แก้ไขราคาและสถานะห้อง
- เพิ่มและแก้ไขผู้เช่า ย้ายออกโดยเก็บประวัติค่าเช่า
- แก้ไขค่าน้ำ ค่าไฟ บันทึกรับชำระ และยกเลิกรายการรับชำระ
- ดูค่าเช่าแยกเดือนและส่งออก CSV ภาษาไทย
- ใช้งานบนมือถือได้

ตรวจการใช้งานจริงด้วย Playwright แล้ว: เพิ่มผู้เช่าและโหลดซ้ำ, แก้ไขห้อง,
ค้นหา, รับชำระและยกเลิก, ส่งออก CSV, ย้ายออก, และหน้าจอ 390–1440 พิกเซล
ภาพตรวจหน้าจออยู่ใน `preview-checks/`

รองรับการลงทะเบียน WebMCP เมื่อเบราว์เซอร์มี `document.modelContext`.
เบราว์เซอร์ที่ใช้ตรวจครั้งนี้ไม่มี API ดังกล่าว จึงยังไม่ได้ยืนยัน WebMCP ในเบราว์เซอร์ที่รองรับจริง
